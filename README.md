### ☸️ **DevOps & Kubernetes — Self-Directed Learning**
#### *A parallel track alongside professional fullstack work — my key differentiator*

> 🎯 Close to a year self-studying DevOps and Kubernetes (YouTube, DevOpsEdu.vn, blogs), applied hands-on by designing, deploying, and operating a small on-premises Kubernetes system end-to-end.

🧪 **Self-Built Project — On-Premises Kubernetes Lab:**
- **Cluster:** 3-node Kubernetes cluster (1 Master, 2 Worker) bootstrapped with `kubeadm`, on-premises servers.
- **Application deployed:** Next.js (frontend), Node.js (backend), MongoDB (database).
- **Deployment automation:** Helm for manifest management and rollout automation.
- **Networking:** Ingress Controller for external traffic routing; a dedicated HAProxy server as Load Balancer.
- **Storage:** Dedicated NFS server combined with PersistentVolume/PVC.
- **Observability:** Prometheus + Grafana for monitoring; centralized logging with the ELK Stack (Elasticsearch, Logstash, Kibana).
- **Cluster management UI:** Rancher.
- First system self-designed, deployed, and operated end-to-end.
